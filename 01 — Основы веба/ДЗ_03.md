# ДЗ 03. Шпаргалка статус-кодов

## Группы кодов своими словами
* 1xx — Информационные: сервер принял запрос, но обработка еще продолжается.
* 2xx — Успех: запрос обработан успешно, клиент получил нужные данные.
* 3xx — Редиректы: запрашиваемый адрес изменился, происходит перенаправление.
* 4xx — Ошибка клиента: запрос составлен неверно (ошибка в URL, нехватка прав).
* 5xx — Ошибка сервера: падение или сбой в коде на стороне сервера.

## Примеры конкретных кодов
* 200 OK — Страница успешно загружена (например, открылась главная страница соцсети).
* 201 Created — Ресурс успешно создан (например, пользователь успешно зарегистрировался).
* 301 Moved Permanently — Постоянный редирект (например, сайт переехал на новый домен).
* 401 Unauthorized — Требуется авторизация (попытка зайти в личный кабинет без логина).
* 404 Not Found — Страница не найдена (клик по старой ссылке на удаленный товар).
* 500 Internal Server Error — Общая внутренняя ошибка сервера (сервер упал при обработке кода).
* 503 Service Unavailable — Сервер временно перегружен (наплыв пользователей в день распродажи).
