# ДЗ 06. Клиент vs сервер — таблица

| Задача | Кто выполняет | Комментарий |
| :--- | :--- | :--- |
| Валидация email | Оба | На клиенте — для быстрого UI, на сервере — для безопасности базы данных. |
| Хранение пароля | Сервер | В браузере пароли хранить небезопасно, сервер хэширует их и прячет в БД. |
| Отрисовка кнопки | Клиент | Браузер (клиент) сам рендерит HTML-код интерфейса. |
| Выдача HTML | Сервер | Сервер отправляет файлы разметки по HTTP-запросу клиента. |
| Отправка письма | Сервер | Письма отправляются через серверные SMTP-протоколы. |
| SEO title | Оба | Изначально генерируется сервером для роботов, но клиентский JS может менять его на лету. |
| Фильтрация списка в UI | Оба | Неболькие списки фильтруются на клиенте, огромные базы данных — на сервере. |
| Запись в БД | Сервер | Прямой доступ к базе данных есть только у сервера из соображений безопасности. |
| CORS | Оба | Сервер задает правила доступа (заголовки), а браузер (клиент) их строго проверяет. |
| CDN картинок | Сервер | CDN — это сеть удаленных серверов для быстрой раздачи статики клиенту. |
| Проверка JWT | Оба | Клиент проверяет срок действия токена, а сервер — его валидность и подпись. |
| Анимация меню | Клиент | Плавные переходы и анимация происходят прямо в браузере с помощью CSS/JS. |
